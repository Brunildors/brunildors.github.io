## The challenge

Since development teams use Azure DevOps, iPORT asked for a way to see each team's capacity, meaning how much work it can take on, from the data that already lives in that tool.

## What we built

Project Atlas is a dashboard hub with login, calendar, projects, alerts, capacity forecasting and an AI assistant, the iPORT AI agent. The interface works in 7 languages.

- **Front end:** React, TypeScript and Vite.
- **Back end:** n8n workflows for the capacity API, authentication and the AI agent.
- **Data:** a PostgreSQL database on Supabase, with tables and functions versioned in SQL.
- **AI:** the assistant uses Gemini, orchestrated by n8n.
