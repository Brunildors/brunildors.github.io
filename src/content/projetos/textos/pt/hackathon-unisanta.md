## O desafio

Como as equipes de desenvolvimento usam o Azure DevOps, a iPORT propôs enxergar a capacidade de cada equipe, ou seja, quanto trabalho ela consegue absorver, a partir dos dados que já existem nessa ferramenta.

## O que construímos

O Projeto Atlas é uma central de painéis com login, calendário, projetos, alertas, previsão de capacidade e um assistente de IA, o agente iPORT AI. A interface funciona em 7 idiomas.

- **Front-end:** React, TypeScript e Vite.
- **Back-end:** fluxos do n8n para a API de capacidade, a autenticação e o agente de IA.
- **Dados:** banco PostgreSQL no Supabase, com tabelas e funções versionadas em SQL.
- **IA:** o assistente usa o Gemini, orquestrado pelo n8n.
